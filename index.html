Engineered for High-Reliability DevOps

Built for developers, agency engineers, and webmasters who need instant verification across Git commits, CMS updates, and production migrations.

Silent Crash Detector

Catches WordPress critical error screens, PHP fatal errors, database connection drops, Django stack traces, and Node unhandled rejections that silently return HTTP 200.

SSL/TLS Health & Expiry

Inspects peer certificate chains, issuers, and remaining days until expiration. Emits automated warnings before certificates expire and trigger browser security blocks.

Concurrent Latency Profiling

High-concurrency thread pooling delivers min, max, avg, and p95 latency percentiles across dozens of routes in under 5 seconds with automatic cache-busting.

SEO & Social Meta Auditor

Scans title tags, meta descriptions, canonical URLs, OpenGraph cards, and flags accidental noindex directives on production environments.

Automated Sitemap Discovery

Parses sitemap.xml and robots.txt directly to automatically discover all critical site routes without needing manual URL lists.

GitHub Actions Step Summaries

Generates rich Markdown summaries directly into $GITHUB_STEP_SUMMARY or PR review comments, providing instant deployment confidence.

Frequently Asked Questions

Generative Engine Optimized answers for technical developers and devops engineers.

How does it catch silent crashes?

The auditor passes response bodies through a pre-compiled engine of known crash signatures for WordPress (WSOD), PHP, Python tracebacks, Next.js hydration errors, and DB connection drops.

Does it bypass CDN caching?

Yes. By default, it appends unique microsecond timestamp parameters (?_health_check=...) to each route, ensuring tests reach the origin web server rather than stale edge caches.

Can I use it as a Python module?

Yes. You can import from site_health_verifier import verify_site directly into your Python test suites, AWS Lambda functions, or Celery workers.
